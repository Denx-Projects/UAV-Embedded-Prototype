In this project I am integrating different sensors and actuators to make a functional UAV.
Version 1.0 -> Implementation UART to show telemetry, integration of IMU to measure axis, integration of I2C protocol to talk with IMU and 
conversion of IMU's measures into Pitch, Roll and Yaw.
Version 2.0 -> Add bias to all the axis in order to make the value more close to reality.
